Ch.04 — AI-Native · Ask Linear · Sprint Plan

Ask Linear
planned the sprint.

With the briefs in place, I asked Linear to plan the two-week sprint. It read the existing sub-issues and proposed a sequenced execution order — not a flat priority list, but a reasoned dependency chain.

  • 1 Map the demo flow first. Defines the structure for everything else. Highest priority.
  • 2 Write talking points next. Depends on the flow — turns it into a usable script. High priority.
  • 3 Dry run and Q&A prep last. Best once story and timing are stable. Medium priority.

This is what AI-native looks like in practice, a tool that reads your actual work and gives something useful back.
